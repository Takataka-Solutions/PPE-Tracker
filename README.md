# PPE Tracker

PPE lifecycle management for Takataka Solutions.

A custom Frappe/ERPNext application for managing and tracking Personal Protective Equipment (PPE) issued to employees at Takataka Solutions (TTS). Part of the HR Module.

## Features

- PPE master records (helmets, gloves, boots, goggles, etc.)
- PPE inventory management
- Employee PPE issuance and return tracking
- PPE replacement management
- PPE expiry monitoring and automated alerts
- Department and location-based PPE allocation
- Compliance and audit reporting

## Installation

```bash
bench get-app ppe_tracker
bench --site [site-name] install-app ppe_tracker
```
